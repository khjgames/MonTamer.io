# Map Screenshots

This directory contains automatically generated map screenshots.

## How to Take Screenshots

1. **Press `=` key** while **NOT** in map editor mode
2. Screenshots will be automatically downloaded to your browser's default download folder
3. Filename format: `map_screenshot_[SCALE]x_[TIMESTAMP].png`

## Screenshot Contents

Each screenshot includes:
- All region tiles (grass tiles, etc.)
- Region borders and boundaries
- Region labels with biome names and difficulty levels
- Grid lines (32-pixel spacing)
- Current scale level applied

## Scale Levels

Screenshots are taken at the current scale level:
- `0.5x` - Half size
- `1x` - Normal size  
- `2x` - Double size
- `4x` - Quadruple size

## File Naming

Examples:
- `map_screenshot_1x_2025-07-27T11-30-45.png`
- `map_screenshot_4x_2025-07-27T11-31-12.png`

## Notes

- Screenshots capture the entire world bounds based on your regions
- Only works when map editor is OFF (press `E` to toggle)
- Images are high-quality PNG format
- Automatic download to browser's download folder
